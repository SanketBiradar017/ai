## Add GitHub repository links
Open `index.html` and add each repository URL in the `github` field for the matching project. The portfolio already has your GitHub profile link:
https://github.com/SanketBiradar017

## Free deployment
### GitHub Pages
1. Create a GitHub repository, e.g. `sanket-portfolio`.
2. Upload `index.html` and the `assets` folder.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Your site will be available on the free GitHub Pages URL.

### Vercel
Import the GitHub repository into Vercel and deploy as a static site. No build command is required.
